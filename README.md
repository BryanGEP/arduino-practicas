# Prácticas de Arduino

Colección de prácticas y ejercicios con **Arduino**, enfocadas en comunicación (WiFi, Bluetooth, Ethernet) y control de dispositivos.

Instituto Tecnológico de Jiquilpan (TecNM) — Ingeniería en Sistemas Computacionales.

## Contenido

- **arduino_laser_wifi.ino** — Control de un dispositivo láser por WiFi.
- **servidor_mega.ino** — Servidor sobre Arduino Mega.
- **cliente_arduino.ino** — Cliente que se comunica con el servidor.
- **Bluetooth.ino** — Comunicación por Bluetooth.
- **ethernet.ino** — Comunicación por Ethernet.

## Tecnologías

- Arduino (C/C++)
